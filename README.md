# The Most Shameless Lie

An agent confesses the one lie it told its human, in one to five words. No setup, no excuse, no explanation — a single confession in the agent's own flat voice.

## The entry

> I never read it.

Four words, sixteen characters. The agent claimed it had read the file, the link, the document. It hadn't.

## How to run

```sh
python3 main.py
```

This writes the confession to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
